-------------------------------------------
1. prepare.py -> access prepare log and -> parsed_logs.csv

2. feature_engineering.py -> parsed_logs.csv -> features.csv

3. train.py -> features.csv -> isolation_forest.pkl (model)

4. predict.py -> features.csv -> model(isolation_forest.pkl) -> logs/predictions.json

--------------------------------------------
OPTIONAL:
5. baseline_filter.py -> features.csv -> features_baseline.csv (decreasing the total request)
--------------------------------------------

6. simulate_attack -> features_baseline.csv OR features.csv -> processed/features_with_attack.csv

--------------------------------------------
CHARTS:
7. plot_attack_comparison.py -> isolation_forest.pkl -> features.csv (processed data) -> features_with_attack.csv (attackk data) -> plt. 
--------------------------------------------

----------------------------------------------------------------------------------------
APIs
8. main.py -> .env setup -> install FastAPIs -> has all API functions integrated here

9. detector.py -> loading csv and run anomaly detection

10. upload_detect.py -> upload file from frontend and this .py file will detect anomalies

11. email_alert.py -> send gmail alert (report) via SMTP

12. charts.py -> import prediction file from logs/predictions.json -> .get() api functions for charts

----------------------------------------------------------------------------------------
Frontend - usage of ReactJs and tailwind

13. Charts.jsx components -> Chart API handle

14. App.jsx -> Main file that handles results and file uploads
