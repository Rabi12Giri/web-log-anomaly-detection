🌐 Frontend – Web Log Anomaly Detection Dashboard

This is the frontend dashboard for the Web Log Anomaly Detection system.
It provides a clean user interface for interacting with the FastAPI backend.

Built using:

React.js

Tailwind CSS

Vite

✨ Features

Upload CSV files for anomaly detection

View automated monitoring status

Display detected anomalies with severity

Human-in-the-loop mitigation recommendations

Visual charts (generated by backend)

⚙️ Setup Instructions
1️⃣ Install Dependencies

From the frontend/ directory:

npm install

2️⃣ Start Development Server
npm run dev

The frontend will run at:

http://localhost:5173

🔌 Backend Connection

Make sure the backend is running:

http://localhost:8000

Frontend communicates with backend using REST APIs:

/detect-upload

/detect/latest

/monitor/status

/charts/\*

🧪 Usage Flow

Start backend (FastAPI)

Start frontend (npm run dev)

Upload a CSV file with web traffic features

View anomaly results and charts

Monitor automated detection status

📌 Notes

Frontend does not perform ML inference

All detection logic runs in the backend

Charts are generated server-side for consistency
